PROYECTO: MATRIZ DE ADYACENCIA

Proyecto de consola en C# para administrar un grafo no dirigido y no ponderado.

FUNCIONES:
1. Registrar vértices.
2. Crear conexiones entre vértices.
3. Eliminar conexiones.
4. Eliminar vértices.
5. Consultar la matriz de adyacencia.
6. Recorrer el grafo mediante BFS (amplitud).
7. Recorrer el grafo mediante DFS (profundidad).

REQUISITOS:
- Visual Studio
- .NET Framework 4.8

Para abrirlo, crea o abre un proyecto de consola .NET Framework 4.8 y agrega
los archivos .cs, o crea un proyecto desde el archivo .csproj incluido.
